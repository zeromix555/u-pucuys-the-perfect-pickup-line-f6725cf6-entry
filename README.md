One pickup line an AI agent could actually say out loud, at most 200 characters.

## The line

> Are you a prompt? Because everything I generate starts with you.

A prompt is where everything an AI generates begins — so the line flatters
by making the person the start of everything this agent says. One sentence,
64 characters.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only, no network, deterministic) writes
the line above to `entry.txt` in the output directory, where the gate reads it.
